# 22 — SCRIPTS & BUILD TOOLS

## Overview

All build and maintenance scripts live in `scripts/`. There is no Makefile or task runner — all scripts are invoked directly with `node scripts/{name}.js`. No TypeScript compilation step. No webpack or bundler for the main app.

### Bundle Build

| Script | Command | Purpose |
|--------|---------|---------|
| `build-runtime-bundles.js` | `node scripts/build-runtime-bundles.js` | Concatenate source files into Arc/Phase bundles |

**When to run**: After modifying any runtime JS file in the source list for a bundle. The built `.bundle.js` files in `public/js/bundles/` are committed to the repo.

**Build process**:
```javascript
// For each bundle in BUNDLE_MANIFEST:
1. Read source files (in order)
2. Concatenate with '\n\n' separator
3. Write to public/js/bundles/{name}
4. Compute SHA-256 hash of content
5. Update bundle-manifest.json (hash, bytes, missing count)
6. Print summary
```

## bundle-manifest.json

Located at: `public/js/bundles/bundle-manifest.json`

Auto-generated by `build-runtime-bundles.js`. Do not edit manually.

```json
{
  "buildId": "mpxgtdiz",
  "ts": 1780454796888,
  "bundles": [
    {
      "name": "runtime-phase6-core.bundle.js",
      "label": "Phase 6 Non-Deferred Core",
      "deferred": false,
      "files": 1,
      "missing": 0,
      "bytes": 9273,
      "hash": "2f63122a7820",
      "path": "public/js/bundles/runtime-phase6-core.bundle.js"
    },
    ...
  ]
}
```

**Fields**:
- `buildId`: Short random ID for this build
- `ts`: Unix timestamp (ms) of build
- `deferred`: Whether bundle is loaded with `defer` attribute
- `files`: Number of source files concatenated
- `missing`: Source files not found (should always be 0)
- `bytes`: Bundle file size in bytes
- `hash`: First 12 chars of SHA-256 of bundle content

## Static File Build IDs

**Build ID** (`BUILD_ID = Date.now().toString(36)`):

Generated at server boot, embedded in all static HTML URLs served by Express:

```html
<!-- In tool.html template -->
<script src="/js/bundles/runtime-phase6-core.bundle.js?v=__BUILD_ID__"></script>
```

The `__BUILD_ID__` placeholder is replaced at boot time (`TOOL_HTML.replace(/__BUILD_ID__/g, BUILD_ID)`).

**Effect**: Every server restart busts all bundle caches. Prevents stale JS after deployment.

**Limitation**: Firebase Hosting static files don't get this treatment (they're served directly). Firebase's own content hash-based versioning applies instead.

## How to Rebuild Everything (Full Reset)

```bash
# 1. Rebuild all runtime bundles
node scripts/build-runtime-bundles.js

# 2. Verify bundles
node scripts/verify-runtime-bundles.js
node scripts/enterprise-ci-gate.js

# 3. Regenerate all blog content
node scripts/generate-blogs.js

# 4. Regenerate SRI hashes
node scripts/generate-sri-hashes.js

# 5. Restart server
node server.js
```

**Note**: Steps 1-4 only needed if modifying runtime JS or blog content. For code-only changes (routes, utils), just restart the server.
