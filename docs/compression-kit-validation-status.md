# Hybrid browser compression: validation status

## Execution contract

- PDF bytes are passed to a same-origin Web Worker as an in-memory Uint8Array; no upload endpoint is used and no network request carries PDF bytes.
- The light engine only considers direct 3-component /DeviceRGB DCT images with no /Mask, /SMask, or /Decode; output quantisation tables are checked coefficient-by-coefficient against the source before acceptance.
- Gray, CMYK, Indexed, Flate, CCITT, JBIG2, masked, and unplaced image streams are preserved by the light engine.
- Image resize is uniform, box-filtered, based on the image's actual placement, never upscales, and skips images already below the 150 DPI floor.
- QPDF is the lossless structural route. AcroForm PDFs use QPDF only; signed, encrypted, and XFA PDFs remain byte-identical.
- Ghostscript candidates are accepted only after page-content SHA-256 checks, structure/protected-stream checks, and the rendered PSNR/sharpness gate. Candidate outputs larger than the input are rejected.
- Custom target work is bounded: light pass + QPDF structural pass + at most two Ghostscript attempts, each starting from the original input. If the target is unreachable, the report says so.

## Regression fixture coverage

| Requirement | Fixture currently in the test suite | Status / limitation |
|---|---|---|
| RGB photo, mixed placement aspect ratios, uniform resize, 150 DPI floor | Deterministic 800×400 RGB JPEG embedded at two placements | Generated fixture; exercises quantisation and placement logic |
| Gray DCT stream remains byte-identical | Valid DeviceGray JPEG padded with a legal JPEG comment segment above the minimum image size | Generated fixture; not a scanner-produced PDF |
| CMYK DCT stream remains byte-identical | Valid Adobe/CMYK JPEG padded above the minimum image size | Generated fixture |
| Soft mask preservation | PDF image with a real /SMask image stream | Generated PDF object fixture |
| 1-bit lossless scan handling | CCITT Group 4 image with /K -1 | Generated fax-like stream; no lossy JBIG2 path |
| Flate-compressed page content | Text/vector page with an explicitly Flate-compressed content stream | SHA-256 is compared after decoding |
| Native link/annotation preservation | URI link annotation in the text/vector fixture | Object graph and annotation count are checked |
| Safe duplicate-image elimination | Two independently embedded identical RGB image objects | Checks dictionary/byte identity, reference rewrite and object removal |
| AcroForm routing | PDF-lib text field | QPDF-only route; Ghostscript deliberately unavailable to the test |
| Encrypted PDF unchanged | PDF encrypted at runtime by QPDF-WASM | Exact input/output byte equality required |
| 100-page document | Runtime-generated 100-page PDF | Structural/page-count regression |
| Signed PDF unchanged | /ByteRange signature-marker guard fixture | **Not a cryptographically signed PDF**; real signed fixture still required |
| Word-exported PDF | Not yet included | **Outstanding**: add a genuine Word-exported PDF fixture |
| Real scanned grayscale PDF | Not yet included | **Outstanding**: current gray image fixture is generated, not a real scanner export |

## Current policy values (not yet empirically calibrated)

The thresholds below are the current conservative policy values. They must **not** be described as tuned from measured Ghostscript/browser gate results until the real browser gate has been run and its psnrDb / sharpnessRatio samples have been recorded.

| Mode | Light JPEG quality ceiling | Target DPI | Floor DPI | Ghostscript QFactor | Minimum PSNR | Minimum sharpness ratio | Calibration evidence |
|---|---:|---:|---:|---:|---:|---:|---|
| Recommended | 78 | 220 | 150 | 0.72 | 32 dB | 0.85 | Not collected in a real browser run |
| Extreme | 58 | 180 | 150 | 0.52 | 28 dB | 0.80 | Not collected in a real browser run |
| Lossless | QPDF only | 300 (policy only) | 150 | Not applied | 40 dB (policy only) | 0.95 (policy only) | QFactor/visual thresholds are not used for the QPDF-only route |
| Custom | 72 | 200 | 150 | 0.62 baseline; bounded attempts use 0.62 then 0.52 | 30 dB | 0.82 | Not collected in a real browser run |

## Release blockers / known limitations

1. The CI attempt observed so far stopped during dependency installation because @types/jpeg-js was requested at a non-existent version. That dependency has been removed; a fresh CI run is still needed. No typecheck, test-suite, or Vite-build pass is claimed here.
2. Browser-rendered quality-gate metrics have not been collected in this environment. The policy values above are therefore **not calibrated** yet.
3. A genuine Microsoft Word-exported PDF and a cryptographically signed PDF are still needed to complete the exact requested fixture matrix.

Because this product is distributed as a web application, review the licence obligations before shipping the WASM bundle; a commercial licence may be required depending on the distribution/deployment model.
