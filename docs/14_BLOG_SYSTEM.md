# 14 — BLOG SYSTEM

## Overview

The blog is a static HTML blog with 37 articles, each a standalone `.html` file. Articles are generated by build scripts and deployed as static files via Firebase Hosting.

**URL pattern**: `/blog/:slug`  
**Index**: `/blog`  
**File location**: `public/blog/*.html`  
**Blog index**: `public/blog.html`

---

## Blog Architecture

### Static File Approach

Each article is a complete HTML file with:
- Full `<head>` with all SEO metadata (title, desc, canonical, OG, Twitter)
- JSON-LD schemas: Article, FAQPage, BreadcrumbList
- Inline article body (1,500–3,000 words)
- Related tool CTAs
- Standard nav/footer

**Why static**: Zero server cost for article serving. Firebase Hosting CDN serves with `Cache-Control: public, max-age=300`. No database queries.

### Generation Scripts

| Script | Purpose |
|--------|---------|
| `scripts/blog-data.js` | Source of truth — all article metadata + content |
| `scripts/generate-blog.js` | Generates individual article HTML files |
| `scripts/generate-blog-listing.js` | Regenerates blog index (`blog.html`) |
| `scripts/generate-blogs.js` | Batch generator (runs both above) |
| `scripts/generate-tool-content.js` | Generates tool description blocks |

**To add a new article**: Add entry to `scripts/blog-data.js` → run `node scripts/generate-blogs.js` → commit `public/blog/` changes.

## Server-Side Blog Routing

From `server.js`:

```javascript
// Blog index — explicit before express.static (prevents directory redirect)
app.get('/blog', (_req, res) => {
  res.set('Cache-Control', 'public, max-age=300');
  res.sendFile(path.join(__dirname, 'public', 'blog.html'));
});

// Blog articles at clean URLs
app.get('/blog/:slug', (req, res, next) => {
  const slug = req.params.slug;
  if (slug.endsWith('.html')) return next();  // skip .html requests
  const filePath = path.join(__dirname, 'public', 'blog', slug + '.html');
  if (fs.existsSync(filePath)) {
    res.set('Cache-Control', 'public, max-age=300');
    return res.sendFile(filePath);
  }
  next(); // 404 if not found
});
```

## Firebase Hosting Blog Integration

From `firebase.json`:
```json
{
  "rewrites": [
    { "source": "/*/preview",  "destination": "/tool.html" },
    { "source": "/*/download", "destination": "/tool.html" },
    { "source": "**",          "destination": "/tool.html" }
  ]
}
```

**Important**: The catch-all rewrite sends everything to `tool.html` — but Firebase serves static files first. Since `public/blog/merge-pdf-guide.html` exists as a physical file, Firebase serves it directly before hitting the rewrite. The clean URL works because `cleanUrls: true` strips `.html`.

## Content Strategy

### Article Structure
1. **Introduction** (150-200 words): What the tool does, why users need it
2. **Step-by-step guide** (H2 section): 4-5 numbered steps with screenshots/descriptions
3. **Tips and tricks** (H2 section): Pro tips for better results
4. **FAQ section** (H2): 5-7 Q&A pairs targeting "People also ask" features
5. **CTA**: Link to the actual tool

### Keyword Strategy
- Primary keyword in H1, first paragraph, meta description, and title
- Long-tail variants in H2 headings and FAQ questions
- Related tool links in article body (internal linking)
- Comparison queries addressed in FAQ (e.g., "Is ilovepdf.cyou free?")

### Content Freshness
- `article:published_time` and `dateModified` in JSON-LD
- Articles can be regenerated with updated dates by re-running build scripts
- No automatic freshness system — manual regeneration required

## Adding/Editing Articles

### Add new article
1. Add entry to `scripts/blog-data.js`:
   ```javascript
   {
     slug: 'my-new-article',
     title: 'How to Do X — Complete Guide',
     description: '...',
     readTime: 5,
     publishedDate: '2024-01-01',
     toolSlug: 'my-tool',  // related tool
     content: `<h2>...</h2><p>...</p>...`,
     faqs: [
       { q: 'Question?', a: 'Answer.' },
       ...
     ]
   }
   ```
2. Run `node scripts/generate-blogs.js`
3. Commit `public/blog/my-new-article.html` + updated `public/blog.html`

### Update existing article
1. Edit the entry in `scripts/blog-data.js`
2. Re-run `node scripts/generate-blogs.js`
3. Commit the updated file

### Delete article
1. Remove from `scripts/blog-data.js`
2. Delete `public/blog/{slug}.html`
3. Re-run `node scripts/generate-blog-listing.js` to update index
